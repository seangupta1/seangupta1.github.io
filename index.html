Deep Learning Single Pedestrian Target Tracking

A deep learning based computer vision system that tracks a selected pedestrian across an entire video by combining PyTorch implementations of Faster R-CNN and a custom Siamese network. The system maintains identity through crowded scenes, occlusions, and target re-entry using cosine similarity and adaptive matching heuristics.
